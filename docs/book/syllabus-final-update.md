- 第一次扫描采用自上而下的目录扫描方法
- 假设目录名称能反映架构重要性
- 忽略了单文件模块和嵌套子系统

- 过度关注"显性"架构（有独立目录的大型模块）
- 忽略了"基础设施层"的架构模式
- 认为"小文件 = 不重要"

### 1.3 文档依赖
- 过度依赖现有文档的完整性
- 现有文档本身就不完整
- 形成"文档盲区"
